Vous écrivez sur un parchemin, du papier ou tout autre matériel d'écriture adéquat et l'imprégnez d'une puissante illusion pour la durée du sort.

Pour vous et toute autre créature que vous désignez lorsque vous lancez ce sort, l'écriture semble normale, écrite de votre main et portant le sens que vous aviez l'intention de transmettre quand vous l'avez écrit. Pour tous les autres, l'écriture parais rédigée dans une langue inconnue ou dans un alphabet magique qui n'est pas compréhensible. Vous pouvez également choisir de faire passer l'écriture pour un tout autre message, écrit d'une main différente et dans une langue que vous connaissez.

Si le sort est dissipé, l'écriture originale ainsi que l'écriture illusoire disparaisse. Une créature avec une vision véritable peut lire le message original.
