Comme réaction que vous pouvez prendre lorsque vous parlez à une créature, vous manipulez habilement les souvenirs de vos auditeurs dans une zone limitée, de telle sorte que toutes les créatures de votre choix dans un rayon de 5 ft. autour de vous oublient tout ce que vous avez dit dans les 6 dernières secondes. Ces créatures se souviennent ensuite que vous avez dit ces 6 dernières secondes les mots que vous avez énoncés comme composante verbale de ce sort.
